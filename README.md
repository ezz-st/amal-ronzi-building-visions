# Amal Ronzi: Building Visions

أنشئ موقعًا احترافيًا وفخمًا وحديثًا لشركة أمل رونزي للمقاولات والاستشارات الهندسية.

الهدف الأساسي من الموقع ليس مجرد التعريف بالشركة، بل بناء الثقة مع الزائر، عرض الأعمال والمشاريع بشكل احترافي، وتحويل الزائر إلى عميل من خلال طلب عرض سعر والتواصل المباشر.

قاعدة مهمة جدًا للصور

ممنوع منعًا باتًا إضافة أو إنشاء أو توليد أو البحث عن أي صور من الإنترنت أو استخدام صور Stock أو صور AI.
استخدم فقط وحصريًا الصور التي سأرسلها لك أنا.
إذا لم أرسل صورة لقسم أو مشروع معين، اترك مكان الصورة كـ Placeholder أنيق وفارغ، ولا تضع أي صورة بديلة من عندك.
لا تستبدل الصور التي أرسلها بصور أخرى.
احتفظ بجودة الصور ونسب أبعادها قدر الإمكان، واعرضها بطريقة احترافية ومتجاوبة على الهاتف والكمبيوتر.
